# 📊 Opportunity Analytics Dashboard

An end-to-end Data Analytics project that analyzes opportunity data using **Python, SQL, and Power BI**. The project demonstrates the complete analytics workflow—from data cleaning and exploration to dashboard development and business insights.

---

## 📌 Project Overview

This project analyzes a dataset containing **5,723 opportunity records**. The objective is to identify patterns in categories, roles, rewards, application fees, locations, eligibility, and posting trends, and present the findings through an interactive Power BI dashboard.

---

## 🎯 Business Problem

Organizations and students often struggle to discover relevant opportunities due to the large number of available options.

The goal of this project is to:

- Understand the distribution of opportunities.
- Identify the most popular categories and roles.
- Analyze rewards and application fees.
- Discover location-wise trends.
- Monitor opportunity posting trends over time.
- Build an interactive dashboard for decision-making.

# 📋 Project Workflow

### 1️⃣ Data Collection

- Imported the raw opportunity dataset.

### 2️⃣ Data Cleaning

- Removed duplicate records.
- Handled missing values.
- Converted date columns.
- Standardized text fields.
- Created additional analytical columns.

### 3️⃣ Exploratory Data Analysis

Performed analysis on:

- Opportunity Categories
- Roles
- Locations
- Rewards
- Application Fees
- Duration
- Eligibility
- Monthly Posting Trends

### 4️⃣ SQL Analysis

Used SQL to answer business questions such as:

- Total Opportunities
- Top Categories
- Top Roles
- Highest Reward Opportunities
- Average Fee by Category
- Monthly Trends
- Top Locations

### 5️⃣ Dashboard Development

Built an interactive Power BI dashboard with:

- KPI Cards
- Slicers
- Bar Charts
- Pie Charts
- Line Charts
- Drill-down Analysis

- Rewards vary considerably across different roles.
- Opportunity postings show noticeable trends over time.
- Some locations consistently offer more opportunities than others.
